# 개인정보 처리방침

내화면에큐알은어떻게찍어? · 2026년 11월 22일

앱은 사용자가 실행한 단축어로 전달받은 화면 이미지를 아이폰에서 분석해 웹 주소와 QR 코드를 읽습니다. 앱은 이미지나 인식한 주소를 저장하지 않으며, 개발자가 운영하는 서버로 전송하지 않습니다.

앱의 설정 진행 상태는 기기에 저장됩니다. 회원 가입은 필요하지 않으며, 앱은 광고, 사용 분석 또는 추적 도구를 사용하지 않습니다.

단축어를 추가할 때 Apple의 공유 페이지가 열릴 수 있습니다. 웹 주소를 열면 기기의 기본 브라우저가 해당 웹사이트에 접속합니다. Apple과 방문한 웹사이트의 데이터 처리는 각 서비스의 개인정보 처리방침을 따릅니다.
