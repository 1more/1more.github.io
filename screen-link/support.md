# 내화면에큐알은어떻게찍어? 지원

화면에 보이는 웹 주소나 QR 코드의 링크를 아이폰에서 여는 앱입니다.

1. 앱에서 **단축어 추가하기**를 누르고 Apple 단축어 추가 화면에서 추가를 확인합니다.
2. 설정 앱에서 **뒷면 탭**을 검색합니다. **두 번 탭**에서 **내화면에큐알은어떻게찍어?** 단축어를 선택합니다. 검색 결과가 없으면 **설정 → 손쉬운 사용 → 터치 → 뒷면 탭**에서 찾을 수 있습니다.
3. 다른 앱에서 웹 주소나 QR 코드가 화면에 보일 때 아이폰 뒷면을 두 번 탭합니다. 주소가 여러 개면 열 주소를 고릅니다.
